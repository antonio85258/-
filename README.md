# ts-practice-1

Выполнено по методичке «Введение в TypeScript - типы и настройка проекта».

## Запуск

```bash
npm install
npx tsc
node dist/index.js
```

Или:

```bash
npm run build
npm start
```

## Ожидаемый вывод мини-проекта

```text
«1984», Джордж Оруэлл, 1949 — прочитана
«Мастер и Маргарита», Михаил Булгаков, 1967 — не прочитана
«Преступление и наказание», Фёдор Достоевский, 1866 — прочитана
Прочитано книг: 2
```

Ошибочные примеры из заданий 2.3 и 3.2 намеренно не добавлены в рабочий `index.ts`, иначе компиляция завершится с ошибками.
